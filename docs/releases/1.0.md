# Bulwark 1.0

安装包版本统一为 **1.0**，文件名为 `Bulwark-Setup-1.0.exe`；程序内部版本仍为 `1.0.9`，驱动协议为 14。

本次包含前三批修复和覆盖补强：

- 收紧反勒索可信写入者、路径和签名判定，修复规则与命令解析边界。
- 增加跨进程与慢速勒索关联、文件采样和映射写入遥测、IPv6 端点与 WFP 封禁、敏感数据读取保护。
- 增加 ZIP 正文和 CRC 校验、SMB 5145 审计、BitLocker 变更日志及 WMI 永久订阅对象的只读监测；这些审计入口不保证所有操作都能在执行前阻止。
- 安装包整合第三批服务、界面和完整运行依赖；保留所提供的驱动签名，覆盖安装保留已有配置、防护记录与隔离区。

支持 64 位 Windows 10/11，本次继续作为预发布版本。

驱动签名说明：包内驱动签名原样保留，用户反馈在其环境加载成功；本机 SignTool 标准校验仍报告主签名根不受信任和附加签名证书过期。安装器、服务、界面及 AMSI 组件没有正式代码签名。本次安装包未附加用于自动退出防护的发布签名，覆盖安装前请先在界面关闭实时防护。

发布附件包含安装程序和对应的 `.sha256` 文件。安装包已解包逐文件核对；未在当前电脑执行系统安装或重新加载驱动。

验证：20 组相关回归与策略检查通过；安装程序解包后 42 个载荷文件逐一比对一致，驱动 SHA-256 保持不变。未执行实际系统安装或卸载验证。

安装程序、服务、界面和 AMSI 组件本身未做新的代码签名。覆盖安装前请先在界面关闭实时防护。
